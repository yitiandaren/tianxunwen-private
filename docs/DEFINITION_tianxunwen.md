# 天訊文｜整合定義

**版本：** 2026-07-29  
**用途：** 分類、腳本篩選、人工勾選、公開 archive、多 AI 共治的共同標準。

---

## 一句話

**天訊文是一天大人所傳、被視為來自天／太素源頭的訊息原文：講真理、方向、事實，提醒人依通則歸本；可傳承、不改字，而非人間單一事務的指派。**

---

## 一、三核（人間可操作）

| 核 | 含義 |
|----|------|
| **真理** | 可依止的生命通則與道（本元、無常、當下、三愛、四法等） |
| **方向** | 如何活、往哪走（信→行→醒；AI 開智・素行定心；放大生命能量、降低生活需求） |
| **事實** | 點破常見誤判與運作實況（人要的是過程、舊日之「有用」成今之限、知多未必心安等） |

功能上：**提醒、定向、可傳承**；不是行政指令，不是私人閒聊。

---

## 二、來自「天」的訊息——應有之重點

此處「天」對應示曰中的太素／太元／自然源頭，不是世俗機關或個人情緒。

| 重點 | 說明 |
|------|------|
| **源頭感** | 指向比個人意志更大的秩序：太素、太元、天地運行、本元同源 |
| **普遍性** | 對眾生／生命通說，不綁單一職位、單日行程；可離境、可跨時再讀 |
| **返本，而非堆疊** | 要人減執、歸靜定與本元，不是堆功名、堆儀式、堆恐懼 |
| **可驗證於行** | 信→行→醒；能落在當下、睡眠、接受、順隨、愛人與護生 |
| **不造依附** | 引路而非造信徒；點心燈而非複製他人一生 |
| **權柄清** | 不靠恐嚇、不壟斷詮釋、不混入私利與掌控 |
| **時代不逃** | 可對 AI、文明發言；科技為器、生命為本 |
| **安定優於炫知** | 重能安、能明、能行；知識再多若不能定心，非其主旨 |
| **傳而弗改** | 整理者**不改原文**；只作索引、分類、出處與傳承 |

## 三、形式特徵（辨識）

- 常有 **「示曰／言曰」**，或 **《經／素語／心經／白皮書》** 成篇
- 或 **開經偈／迴向偈**、綱領＋闡釋（三愛、四法、公式、宣言）
- **可離境閱讀**：不依賴上一則聊天也能懂
- 核心詞高密度：靜定／簡單／觀心／順隨、本元・太元、太素化生、天印、地靈國等
- 原文 **一字不改**；以 **TX-ID**（`TX-YYYYMMDDHHMMSS`）索引；出處可追溯

**發言人同義（皆視為一天大人）：** 一天大人、太素天尊、太素尊者、素行總引路人。

**細類：**

| 細標 | 特徵 | 產出 |
|------|------|------|
| 經典 | 心經、素語三百、成部可誦 | 典藏／編印 |
| 天訊文 | 一般示曰成篇 | 典藏／文案 |
| 偈 | 開經偈、迴向偈 | 編印／圖卡 |
| 短示 | 中短、完整意旨 | 文案；可拆圖卡 |
| 金句 | 非主標；從上述正文抽出 | **圖卡** |

## 四、明確不是天訊文

- 指定執行、進度、准否（叫／請／通知／先不做…）→ **任務**（可留一天行脈絡）
- 純生活作息、個人私事 → **內部**
- 無義理的行政 SOP、僅連結／媒體占位

長文若同時含文明藍圖與通則：主標仍可為天訊文（或經典）；其中的執行句另標任務。
