# 天訊文整理工作流（定稿）

**原則順序（不可跳步）**

```
① 整合全部對話
② 去重
③ 分類（天訊文｜任務＋關聯脈絡）
④ 分支細做（天訊文處理｜任務執行紀錄）
```

**天訊文定義全文：** 見 [`docs/DEFINITION_tianxunwen.md`](./DEFINITION_tianxunwen.md)  
**一句話：** 一天大人所傳、被視為來自天／太素的原文；講**真理、方向、事實**；可傳承、不改字；非單一事務指派。

---

## 一、總流程

```
raw/whatsapp/*.txt 或 raw/line/*.txt   ← 完整對話匯出
        │
        ▼
① 整合：時間對齊、來源可追溯
        │
        ▼
② 去重：一天大人原文相同只留一則
        │   master/whatsapp/ 或 master/line/
        │   （一字不改、TX-ID 到秒）
        ▼
③ 分類
        ├─ 天訊文清單     → classify/tianxunwen_*.csv/.md
        ├─ 任務＋互動脈絡 → classify/tasks_*.csv/.md
        └─ 需前因者標註，保留相關訊息
        │
        ▼
④a 天訊文：細標 → 人工勾選 → 公開 archive／文案／圖卡
④b 任務：細節、執行、回報、結案（內部）
```

| 階段 | 輸入 | 產出 | 是否改原文 |
|------|------|------|------------|
| ① 整合 | 多份匯出 | `raw/` | 否 |
| ② 去重 | raw | `master/…/YYYY-MM-DD.md` | 否（只刪重複則） |
| ③ 分類 | 完整對話 raw | 天訊文表＋任務脈絡表 | 否 |
| ④a 天訊文 | 天訊文清單 | 公開 `TX-*.md`、圖卡 | 正文不改 |
| ④b 任務 | 任務脈絡表 | 內部執行紀錄 | — |

**發言人同義（皆為一天大人）：** 一天大人、太素天尊、太素尊者、素行總引路人。

## 二、去重演算法設計

### 2.1 目標

- 一天大人訊息：全文相同只保留一則（最早或首次出現）
- **一字不改**；不合併、不改寫、不摘要
- 給穩定 **TX-ID**，便於跨檔引用與公開 archive 對齊

### 2.2 解析

**WhatsApp：** 時間戳 `[YYYY/M/D … H:MM:SS] 發言人: 內容`  
**LINE：** 日期行 `YYYY/MM/DD（…）` + `上午|下午HH:MM 發言人 內容`（見 `scripts/process_line_tianxunwen.py`）

共通：

1. 剝除 LTR/RTL 控制字元
2. 跨行併入同一則
3. 只保留一天大人同義發言（master 層）
4. 略過純媒體占位

### 2.3 去重鍵

| 方案 | 鍵 | 說明 |
|------|-----|------|
| **採用** | 正規化後全文精確雜湊（SHA-256） | trim、換行統一 |
| 不採用 | 僅時間戳／模糊相似度 | 天訊文不可近似合併 |

同一雜湊只留**第一次**出現。

### 2.4 TX-ID

```
TX-YYYYMMDDHHMMSS
```

公開 archive 與私庫 **同一 TX-ID 對齊**。

### 2.5 腳本

```bash
# WhatsApp
python scripts/process_whatsapp_tianxunwen.py raw/whatsapp/某檔.txt \
  --output-dir master/whatsapp --source-name 某檔.txt

# LINE
python scripts/process_line_tianxunwen.py raw/line/某檔.txt \
  --output-dir master/line --source-name 某檔.txt
```

## 三、天訊文分類標準

完整定義見 **DEFINITION_tianxunwen.md**。此處為操作摘要。

### 3.0 三核（判定時自問）

1. 是否在講 **真理**（通則／道）？
2. 是否給出 **方向**（如何活、往哪走）？
3. 是否點明 **事實**（運作實況、常見誤判）？

是，且可離境讀 → 優先天訊文。  
僅叫人辦事／准否／進度 → 任務。

### 3.1 功能主標（9 類）

| 功能主標 | 定義 |
|----------|------|
| **天訊文** | 講真理／方向／事實；示曰、心經／白皮書級 |
| **修行指示** | 唸、坐、迴向、儀軌等可執行修持 |
| **任務指派** | 要一天行（或他人）執行的事務 |
| **詢問確認** | 問進度、要回報 |
| **決策拍板** | 准／不准、先做／先不做 |
| **組織推廣** | 品牌、出版、園區行政 SOP（**非**心經級正文） |
| **生活作息** | 吃、睡、行程、保養 → **內部不公開** |
| **個人私事** | 明顯私人 → **內部不公開** |
| **回應回報** | 針對上一則的直接回覆 |

### 3.2 天訊文細標

| 細標 | 特徵 | 產出 |
|------|------|------|
| **經典** | 心經、素語三百、成部可誦 | 文案／編印／典藏 |
| **天訊文** | 一般示曰成篇 | 文案／典藏 |
| **偈** | 開經偈、迴向偈 | 編印／圖卡 |
| **短示** | 中短、完整意旨 | 文案；可拆圖卡 |
| **金句** | 非主標；從經典／天訊文／短示抽出 | **圖卡** |

### 3.3 判定順序

```
1. 生活作息／個人私事 → 對應主標，公開＝否
2. 示曰／《經》／長篇核心思想／三核成立 → 天訊文（＋細標）
3. 決策拍板短句 → 決策拍板
4. 執行事務動作 → 任務指派
5. 問進度 → 詢問確認
6. 修持動作 → 修行指示
7. 推廣／園區 SOP 且無示曰、無三核 → 組織推廣
8. 其餘 → 待標
```

### 3.4 強訊號（自動化）

1. 「示曰」或「言曰」且成段（建議 ≥60 字）
2. 《標題》且長文（心經、素語、白皮書等）
3. 開經偈／迴向偈 → 偈
4. 核心詞（本元、太素、靜定、簡單、觀心、順隨、三愛、信行醒、地靈國、天印…）＋足夠長度

### 3.5 排除（非天訊文）

- 飲食、行程、保養、叫人辦事短句
- 純數字、極短附和、僅媒體占位
- 無示曰、無三核的行政 SOP

### 3.6 金句

只從「公開＝是」且主標＝天訊文的正文抽取；不從任務句抽。

### 3.7 脈絡

| 標記 | 含義 |
|------|------|
| **可獨立** | 不依賴上一則也能懂 |
| **需前因後果** | 決策、督促、准否等 |

### 3.8 公開與否

| 公開＝是 | 公開＝否 |
|----------|----------|
| 天訊文（經典／天訊文／偈／短示） | 生活作息、個人私事 |
| 可公開的修行指示（視內容） | 任務、決策、詢問、組織 SOP |
