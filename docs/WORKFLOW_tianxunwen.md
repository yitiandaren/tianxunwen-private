# 天訊文整理工作流（定稿）

**原則順序（不可跳步）**

```
① 整合全部對話
② 去重
③ 分類（天訊文｜任務＋關聯脈絡）
④ 分支細做（天訊文處理｜任務執行紀錄）
```

---

## 一、總流程

```
raw/whatsapp/*.txt          ← 各方完整對話匯出（含一天行）
        │
        ▼
① 整合：時間對齊、來源可追溯、多檔合併準備
        │
        ▼
② 去重：一天大人原文相同只留一則 → master/whatsapp/YYYY-MM-DD.md
        │                         （一字不改、TX-ID 到秒）
        ▼
③ 分類（對完整對話 raw，或 master＋raw 對照）
        ├─ 天訊文清單     → classify/tianxunwen_*.csv/.md
        ├─ 任務＋互動脈絡 → classify/tasks_*.csv/.md
        └─ 需前因者標註，保留相關訊息
        │
        ▼
④a 天訊文：細標 → 人工勾選 → 公開 archive／文案／圖卡
④b 任務：細節、執行、回報、結案（內部，不進公開 archive）
```

| 階段 | 輸入 | 產出 | 是否改原文 |
|------|------|------|------------|
| ① 整合 | 多份 WhatsApp 匯出 | 置於 `raw/whatsapp/` | 否 |
| ② 去重 | raw | `master/whatsapp/YYYY-MM-DD.md` | 否（只刪重複則） |
| ③ 分類 | 完整對話 raw | 天訊文表＋任務脈絡表 | 否 |
| ④a 天訊文 | 天訊文清單 | 公開 `TX-*.md`、圖卡 | 正文不改 |
| ④b 任務 | 任務脈絡表 | 內部執行紀錄 | — |

## 二、去重演算法設計

### 2.1 目標

- 一天大人訊息：全文相同只保留一則（最早或首次出現）
- **一字不改**；不合併、不改寫、不摘要
- 給穩定 **TX-ID**，便於跨檔引用與公開 archive 對齊

### 2.2 解析

1. 讀取 WhatsApp 匯出 `.txt`
2. 以時間戳正則切則：
   ```
   [YYYY/M/D 上午|下午|…]H:MM:SS] 發言人: 內容
   ```
3. 剝除 LTR/RTL 控制字元（`\u200e` 等）
4. 跨行內容併入同一則，直到下一則時間戳
5. **只保留發言人含「一天大人」或「太素天尊」的則**（master 層）
6. 略過純媒體占位：`圖像已省略`、`影片已省略`、`貼圖已忽略` 等

### 2.3 去重鍵

| 方案 | 鍵 | 說明 |
|------|-----|------|
| **採用** | 正規化後全文的精確雜湊（建議 SHA-256） | 空白正規化：首尾 trim、換行統一為 `\n` |
| 不採用 | 僅時間戳 | 同一秒可能多則 |
| 不採用 | 模糊相似度 | 天訊文不可「近似合併」 |

**正規化（僅供比對，寫入 master 仍用原文）：**

- `strip()` 首尾空白
- 統一換行
- 可選：連續空白壓成單一空格（若啟用須全專案一致）

**保留策略：** 同一雜湊只留**第一次**出現的則（時間較早）；後續重複捨棄並可計入「去重略過數」。

### 2.4 TX-ID

```
TX-YYYYMMDDHHMMSS
```

- 由該則時間戳產生
- 同一秒多則：可加後綴 `-2`、`-3`（若發生）
- 公開 archive 與私庫 **同一 TX-ID 對齊**

### 2.5 master 日檔格式

```markdown
## TX-20260604111101

原文：
一天大人示曰：
…

出處：raw/whatsapp/某檔.txt
```

- 按日一個檔：`master/whatsapp/2026-06-04.md`
- 檔內多則以 `---` 分隔

### 2.6 批次與冪等

- 新 raw 再跑：只追加「雜湊未見過」的則
- 可維護全域 `seen_hashes`（檔或記憶體）跨檔去重
- 重跑同一檔：master 對應日檔可覆蓋或合併，以雜湊為準避免雙份

### 2.7 腳本

```bash
python scripts/process_whatsapp_tianxunwen.py raw/whatsapp/某檔.txt \
  --output-dir master/whatsapp \
  --source-name 某檔.txt
```

## 三、天訊文分類標準

### 3.1 功能主標（9 類）

| 功能主標 | 定義 |
|----------|------|
| **天訊文** | 傳法、示曰、心經／白皮書級長文（原「開示」） |
| **修行指示** | 唸、坐、迴向、儀軌等可執行修持 |
| **任務指派** | 要一天行（或他人）執行的事務 |
| **詢問確認** | 問進度、要回報 |
| **決策拍板** | 准／不准、先做／先不做 |
| **組織推廣** | 品牌、出版、園區 SOP、演講方向（**非**心經級正文） |
| **生活作息** | 吃、睡、行程、保養 → **內部不公開** |
| **個人私事** | 明顯私人 → **內部不公開** |
| **回應回報** | 針對上一則的直接回覆（可與決策／詢問並用） |

主標一個；必要時副標一個（例如：天訊文｜組織推廣）。

### 3.2 天訊文細標（僅主標＝天訊文）

| 細標 | 特徵 | 產出 |
|------|------|------|
| **經典** | 心經、素語三百、成部可誦 | 文案／編印／典藏 |
| **天訊文** | 一般示曰成篇 | 文案／典藏 |
| **偈** | 開經偈、迴向偈、固定偈頌 | 編印／圖卡 |
| **短示** | 中短、完整意旨 | 文案；可拆圖卡 |
| **金句** | **不是主標**；從經典／天訊文／短示正文抽出的圖卡句 | **圖卡** |

### 3.3 判定順序（腳本與人工共用）

```
1. 生活作息／個人私事關鍵 → 主標對應，公開＝否
2. 示曰／《經》／長篇核心思想 → 天訊文（＋細標）
3. 決策拍板短句 → 決策拍板
4. 執行事務動作 → 任務指派
5. 問進度 → 詢問確認
6. 修持動作 → 修行指示
7. 推廣／園區 SOP 且無示曰 → 組織推廣
8. 其餘 → 待標
```

**邊界：**

| 情況 | 處理 |
|------|------|
| 示曰長文末句「去做短影音」 | 主標＝天訊文；任務句另標或副標 |
| 白皮書／心經級 | **主標偏天訊文**（經典或天訊文） |
| 無示曰的公頃／公式 SOP | 組織推廣，公開＝否 |
| 「先不做」 | 決策拍板，**需前因** |

### 3.4 天訊文強訊號（自動化）

1. 含 **「示曰」** 或 **「言曰」** 且成段（建議 ≥60 字）
2. 有 **《標題》** 且長文（心經、素語、白皮書等）
3. **開經偈／迴向偈** 結構 → 細標＝偈
4. 核心詞（本元、太素、靜定、簡單、觀心、順隨、三愛、信行醒、地靈國、天印…）＋足夠長度 → 輔助加分

### 3.5 明確排除（非天訊文）

- 飲食、行程、保養、叫人辦事短句
- 純數字、極短附和
- 僅媒體占位
- 無示曰的短視頻公式、園區行政 SOP

### 3.6 金句

- **只從**「公開＝是」且主標＝天訊文的正文抽取
- 不從聊天短訊、任務句抽
- 自動給候選；定稿需人工

### 3.7 脈絡

| 標記 | 含義 |
|------|------|
| **可獨立** | 不依賴上一則也能懂（多數成篇示曰） |
| **需前因後果** | 決策、督促、對提案的准否、數字回覆等 |

需前因：分類表標註；必要時寫前因摘要，或連結 raw 中一天行相關則。

### 3.8 公開與否

| 公開＝是 | 公開＝否（另檔內部） |
|----------|----------------------|
| 天訊文（經典／天訊文／偈／短示） | 生活作息、個人私事 |
| 可公開的修行指示（視內容） | 任務指派、詢問確認、決策拍板、組織推廣 SOP |

內部建議路徑：`classify/internal/YYYY-MM_internal.csv`

## 四、任務分類與互動脈絡

### 4.1 目的

任務與天訊文**分開**。  
一天大人指派／決策時，若與一天行對話有關，**必須留下相關訊息（上下文）**，供後續執行與結案。

### 4.2 任務錨點（一天大人）

- 任務指派：叫、請、讓、通知、傳、設計、拍、上傳…
- 決策拍板：先不做、可以、就這樣…
- 詢問確認：進度、好了沒…
- 短生活安排可標生活作息（仍入任務／內部線，不入天訊文）

**示曰長文不當任務錨點。**

### 4.3 脈絡窗

- 以錨點則為中心，前後各 N 則（預設 **3**）
- 窗內保留一天大人與**一天行**（及必要其他發言）
- 標記 `含一天行＝是／否`

### 4.4 產出

```
classify/tasks_<檔名>.csv
classify/tasks_<檔名>.md   # 每則含脈絡全文，★ 為錨點
```

後續④b：依任務表做執行細節、回報、結案（內部庫，本文件不規定欄位細節）。

## 五、腳本對照

| 階段 | 腳本 | 說明 |
|------|------|------|
| ② 去重 | `scripts/process_whatsapp_tianxunwen.py` | raw → master |
| ③ 天訊文篩選 | `scripts/screen_tianxunwen.py` | 細標、可抽金句 |
| ③ 雙線分類 | `scripts/extract_tianxunwen_and_tasks.py` | **天訊文＋任務脈絡**（需完整對話） |
| 一鍵 | `scripts/run_tianxunwen_pipeline.py` | 去重＋篩選 |
| 批量 | `scripts/batch_run.sh` | 本機多檔 |
| CI | `.github/workflows/` | push raw 或手動 |

### 建議指令

```bash
# ② 去重
python scripts/process_whatsapp_tianxunwen.py raw/whatsapp/完整對話.txt \
  --output-dir master/whatsapp

# ③ 天訊文 + 任務脈絡（同一完整對話）
python scripts/extract_tianxunwen_and_tasks.py raw/whatsapp/完整對話.txt \
  --context 3 \
  --outdir classify

# 僅天訊文細篩＋金句候選
python scripts/screen_tianxunwen.py raw/whatsapp/完整對話.txt \
  --only 天訊文 \
  --extract-jinju \
  --csv classify/screen.csv \
  --md-report classify/screen.md
```

## 七、人工邊界（不可全自動）

1. **需前因後果**的短指令：對 raw 核對一天行上下文
2. 長篇規劃／白皮書是否公開、主標是否維持天訊文
3. 金句定稿與圖卡選句
4. 公開 archive 前勾選清單；subject／category／related_ids 品質
5. 個人私事敏感內容：腳本粗標，人把關

---

## 八、與公開 archive 銜接

1. 從天訊文清單勾選 `公開＝是`
2. 套公開 YAML 範本（tx_id、show_time、原文、CC BY-ND 4.0…）
3. 正文與 master／raw **一字不改**
4. 推送到公開 `tianxunwen/archive/`

私庫負責完整、可驗證；公開庫負責可傳播的天訊文成品。
