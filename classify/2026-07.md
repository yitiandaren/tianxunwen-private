# 2026-07 一天大人文字訊息分類（全月）

## 一、通用分類規則

| 欄位 | 說明 |
|------|------|
| 功能 | 開示｜修行指示｜任務指派｜決策拍板｜詢問確認｜生活作息｜個人私事｜組織推廣 |
| 對象 | 一天行｜一天律｜一天化｜團隊｜具名外人｜不特定眾人｜自己｜事務 |
| 脈絡需求 | **可獨立**｜**需前因後果** |
| 前因摘要 | 僅需前因後果時填 |

原則：對話為「一天大人 ↔ 一天行」或群組，非自問自答。主檔原文一字不改。

---

## 二、開示細分類（僅功能含「開示」時填）

依**內容長短與格式**，決定可做圖卡或文案：

| 細類 | 特徵 | 建議產出 |
|------|------|----------|
| **金句** | 一句～數句、對仗或可獨立成卡、通常 < 80 字 | **圖卡**（優先）；亦可作短影音字幕 |
| **短開示** | 一段～數段、有完整意旨、約 80～400 字 | **文案**（貼文／短篇）；可拆句做圖卡系列 |
| **天訊文** | 多有「示曰」、標題、成篇結構、較長可典藏 | **文案**（完整發布／archive）；可另抽金句做圖卡 |
| **誓願文** | 祈願、十二願、立約體 | **文案＋編印**（如素生經）；不宜只當單句圖卡 |

產出欄簡寫：`圖卡`｜`文案`｜`圖卡+文案`｜`編印`｜`—`（非公開開示）
