# tianxunwen-private

**一天大人原始文字內容典藏庫（天訊文原始層）**

## 定位
完整收集一天大人所有文字訊息，進行去重，嚴格保留原文，禁止任何修改。

## 核心原則
1. **完整收集**：盡可能收錄所有文字訊息
2. **去重**：同一則訊息不重複出現
3. **一字不改**：任何文字都不可修改（因為是來自天的訊息）
4. **可追溯**：每則訊息保留原始時間與來源

## 資料夾結構

```
tianxunwen-private/
├── raw/                  ← 原始完整檔案（完全不動）
│   └── whatsapp/
├── master/               ← 去重後的總庫（最終依據）
│   └── whatsapp/
└── governance/           ← 規則與說明
```

## 使用說明
- `raw/`：保存原始上傳檔案，作為最終備份
- `master/`：經過去重、依時間排序的完整文字庫
- 分類標籤可之後再加，但不碰原文
